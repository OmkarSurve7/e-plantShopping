# Paradise Nursery ??

An online plant shop built with React and Redux.

## Features
- Browse plants by category (Air Purifying, Aromatic, Insect Repellent, Medicinal, Low Maintenance)
- Add items to cart
- Adjust quantities
- Remove items
- Checkout (coming soon)

## Technologies
- React
- Redux Toolkit
- Vite

## How to run
1. Clone the repo
2. Run 
pm install
3. Run 
pm run dev
4. Open http://localhost:5173
